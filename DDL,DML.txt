Error that's I face it:

1. Foreign Key Dependency Error

When I tried to insert records into the Employee table, I get a foreign key constraint error because the employee records referenced departments that had not been inserted into the Department table yet. To solve this problem, I cleared the employee data and inserted the department records first, then inserted the employee records.

also used "TRUNCATE" to remove all rows.

2. Missing Department Location Data

I forgot to insert records into the Depet_loc table. As a result, when I performed JOIN queries involving department locations, no location data was returned. Fixed that by inserting the missing location records.

3. Missing Foreign Key Constraints

While creating the tables, I forgot to add some foreign key constraints to certain tables. This caused relationships between tables not to be enforced correctly. I solved the problem by using ALTER TABLE statements to add the required foreign key constraints after the tables were created.
