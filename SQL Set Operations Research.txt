SQL Set Operations Research: UNION, INTERSECT, and EXCEPT

Introduction

SQL set operations are used to combine or compare the results of two or more `SELECT` statements. The three primary set operations are:

1.UNION
2.INTERSECT
3.EXCEPT (called `MINUS` in Oracle SQL)

These operations are useful when working with data from multiple tables or comparing query results.

---
1. UNION

Definition

The `UNION` operator combines the results of two or more `SELECT` statements into a single result set.

* Removes duplicate rows automatically.
* Used when you want all unique records from multiple queries.

When to Use

* Combining data from similar tables.
* Merging lists from different departments, locations, or sources.

---
Syntax


SELECT column1, column2, ...
FROM table1

UNION

SELECT column1, column2, ...
FROM table2;


---

Rules & Conditions

1. Each `SELECT` statement must have the same number of columns.
2. Corresponding columns must have compatible data types.
3. Column names in the final result come from the first query.
4. Duplicate rows are removed automatically.
5. `ORDER BY` can only appear once at the end of the final query.

---

UNION vs UNION ALL

UNION

Removes duplicate rows.

SELECT department_id
FROM employees

UNION

SELECT department_id
FROM departments;


Result: Unique department IDs only.

---

UNION ALL

Keeps all rows, including duplicates.


SELECT department_id
FROM employees

UNION ALL

SELECT department_id
FROM departments;


Result: All department IDs, including duplicates.

Practical Example (HR Schema)

Suppose we want a list of all department IDs that either have employees or are listed in the departments table.

SELECT department_id
FROM employees

UNION

SELECT department_id
FROM departments;
Result

Returns a unique list of department IDs from both tables.
---

2. INTERSECT

Definition

The `INTERSECT` operator returns only rows that appear in both result sets.

Think of it as finding the common records between two queries.

When to Use:

* Finding shared values between tables.
* Identifying employees that meet multiple conditions.
* Comparing datasets for overlap.

---

Syntax

SELECT column1, column2, ...
FROM table1

INTERSECT

SELECT column1, column2, ...
FROM table2;


---

Rules & Conditions:

1. Both queries must return the same number of columns.
2. Corresponding columns must have compatible data types.
3. Duplicate rows are removed.
4. Only rows present in both queries are returned.

Practical Example (HR Schema)

Find department IDs that exist in both the Employees and Departments tables.

SELECT department_id
FROM employees

INTERSECT

SELECT department_id
FROM departments;
Result

Returns department IDs that have employees and also exist in the departments table.
---

3. EXCEPT (MINUS in Oracle)

Definition

The `EXCEPT` operator returns rows from the first query that do not appear in the second query.

Oracle uses the keyword `MINUS` instead of `EXCEPT`.
When to Use:

* Finding missing records.
* Identifying differences between datasets.
* Locating employees who are not managers.

---

Syntax

SQL Server / PostgreSQL:


SELECT column1, column2, ...
FROM table1

EXCEPT

SELECT column1, column2, ...
FROM table2;


Oracle:


SELECT column1, column2, ...
FROM table1

MINUS

SELECT column1, column2, ...
FROM table2;
```


Rules & Conditions:

1. Same number of columns in both queries.
2. Compatible data types are required.
3. Duplicate rows are removed.
4. Only rows from the first query that do not exist in the second query are returned.

Practical Example (HR Schema)

Find department IDs that exist in the Departments table but have no employees assigned.
SELECT department_id
FROM departments

MINUS
SELECT department_id
FROM employees;
